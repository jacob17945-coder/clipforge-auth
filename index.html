ClipForge privacy policy

ClipForge is a personal desktop tool that runs only on its owner's own computer. It posts videos to the owner's own YouTube, Instagram and TikTok accounts after the owner approves each one.

What it accesses: your basic profile (username, account id), permission to publish videos you approve, and view counts for those videos.

Where data goes: login tokens and video statistics are stored only on the owner's computer. Nothing is sold, shared with third parties, or sent to any server run by ClipForge (there isn't one).

YouTube: ClipForge uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of your data is covered by the Google Privacy Policy. You can revoke ClipForge's access at any time at Google security settings.

Deleting data: remove the app in Google (link above), Instagram (Settings -> Website permissions -> Apps and websites) or TikTok (Settings -> Security -> Manage app permissions) and delete the ClipForge "secrets" folder. Questions: open an issue on this GitHub repository.
